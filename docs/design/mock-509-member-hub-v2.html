One band instead of two. 2 — the metabox unrolls sideways. AFFILIATIONS is deleted outright — the header meta line already carries the badges. 3 — five stacked sections became one tabbed box. Bills · Votes · Committees · Amendments · Press · Trades, counts on the tabs, zero-count tabs at 50% opacity (the .search-tabs [data-empty] idiom). The out-link on the right swaps with the tab. Body is a fixed 430px with internal scroll, so a tab swap never resizes the box (the HO 244 .distributions-panel-body rule).
Precedent, not invention: ActivityTabs (HO 132/249) is a "use client" island that takes pre-rendered ReactNodes as props — the server page keeps every fetch, the island holds only useState. Same shape here. Chrome is .search-tabs + .breaking-stalls-tabs, already shipped.
The tradeoff to say yes or no to: a tab means Ctrl-F only searches the open panel, and you can't see bills and votes at once. If that bothers you, the middle option is Bills stays always-visible below the hero and only the four short lists get tabbed — costs about 400px.
